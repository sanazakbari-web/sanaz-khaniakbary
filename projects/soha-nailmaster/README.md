# SOMA STUDIO | soha-nailmaster

قالب اختصاصی وردپرس برای استودیو خدمات ناخن، با رابط فارسی و راست‌به‌چپ.

## امکانات

- صفحات خانه، درباره ما، خدمات، گالری و رزرو.
- انتخاب تاریخ شمسی، بررسی زمان‌های قابل رزرو و انتخاب خدمات و خدمات تکمیلی.
- محاسبه مبلغ خدمات و بیعانه؛ هماهنگی جداگانه برای خدمات VIP و Signature.
- اتصال پرداخت بیعانه به WooCommerce؛ درگاه پرداخت از تنظیمات ووکامرس پیکربندی می‌شود.
- مدیریت رزروها و قیمت‌ها در پیشخوان وردپرس.
- اتصال به ملی پیامک برای اعلان رزرو، یادآوری سه ساعت پیش از نوبت و پیگیری ماهانه؛ نیازمند تنظیم حساب پیامک و اجرای WP-Cron.
- طراحی واکنش‌گرا، تصاویر و فونت‌های همراه قالب.

## نصب

1. یک نصب مستقل وردپرس با PHP 8.3 یا بالاتر و MySQL/MariaDB آماده کنید.
2. پوشه `wp-content/themes/somsa-studio` را در مسیر قالب‌های همان وردپرس کپی کنید.
3. WooCommerce را نصب و فعال کنید و تنظیمات فروشگاه، واحد پول و درگاه پرداخت را انجام دهید.
4. از «نمایش ← پوسته‌ها»، قالب **SOMA STUDIO** را فعال کنید.
5. برگه‌هایی با نامک‌های `home`، `about`، `services`، `gallery` و `booking` بسازید. برگه `home` را از تنظیمات خواندن به‌عنوان صفحه اصلی ایستا انتخاب کنید.
6. پیوندهای یکتا را ذخیره کنید. تنظیمات رزرو و پیامک را در پیشخوان بررسی کنید؛ اطلاعات حساب پیامک را فقط در پیشخوان وارد کنید.
7. برای استفاده عملی، درگاه پرداخت، ارسال پیامک و زمان‌بندی را در محیط خودتان آزمایش کنید.

فعال‌سازی قالب، جدول‌های مورد نیاز رزرو و پیامک را ایجاد می‌کند. داده‌ها و تنظیمات سایت اصلی در این مخزن نیستند؛ بنابراین نصب قالب به‌معنای انتقال کامل سایت اصلی نیست.

## ساختار

- `functions.php`: خدمات، مبلغ رزرو، دسترسی زمان‌ها و اتصال ووکامرس.
- `sms.php`: تنظیمات، صف پیامک و زمان‌بندی پیام‌ها.
- `page-*.php`: صفحات داخلی.
- `assets/`: جاوااسکریپت، تصاویر و فونت‌ها. مجوز فونت همراه در `assets/FONT-LICENSE.txt` آمده است.
- `tests/`: آزمون‌های موجود پروژه. آزمون‌های PHP به وردپرس و پایگاه داده نیاز دارند و داده آزمایشی می‌سازند؛ آن‌ها را روی نصب آزمایشی اجرا کنید.

## Development check

The custom theme source is included; WordPress core, plugins, database exports, customer records and service credentials are excluded. PHP syntax can be checked without loading WordPress. The included database tests require a separate test installation.

# Webora

قالب اختصاصی وردپرس برای معرفی خدمات طراحی سایت و نمایش نمونه‌کارها.

## امکانات

- صفحه اصلی با بخش‌های معرفی، نمونه‌کارها، خدمات، فرایند همکاری و تماس.
- فیلتر نمونه‌کارها و نمایش جزئیات پروژه در پنجره تعاملی.
- طراحی واکنش‌گرا و منوی موبایل.
- لینک‌های ایمیل، اینستاگرام، لینکدین و GitHub قابل تنظیم در سفارشی‌ساز وردپرس.
- فرم تماس، پیش‌نویس ایمیل را با `mailto:` در برنامه ایمیل باز می‌کند؛ سرویس ارسال ایمیل سمت سرور ندارد.
- رابط انگلیسی با رنگ‌بندی صورتی و زرشکی و تایپوگرافی اختصاصی.

## نصب

1. یک نصب مستقل وردپرس با PHP 8.3 یا بالاتر آماده کنید.
2. پوشه `wp-content/themes/webora` را در مسیر قالب‌های وردپرس کپی کنید.
3. از «نمایش ← پوسته‌ها»، قالب **Webora** را فعال کنید.
4. یک برگه خانه بسازید و از تنظیمات خواندن به‌عنوان صفحه اصلی ایستا انتخاب کنید.
5. اطلاعات تماس را از «نمایش ← سفارشی‌سازی ← Webora — Contact links» ویرایش کنید.
6. متن خدمات و نمونه‌کارها در `front-page.php` قرار دارد. پیش از انتشار واقعی، محتوای نمونه و رفتار فرم تماس را متناسب با نیاز خود بررسی کنید.

## Files

- `front-page.php`: صفحه اصلی و محتوای بخش‌ها.
- `functions.php`: امکانات قالب، بارگذاری فایل‌ها و سفارشی‌سازی لینک‌های تماس.
- `style.css`: ظاهر قالب و تنظیمات نمایش در موبایل.
- `site.js`: منوی موبایل، فیلترها و تعاملات صفحه.
- `index.php`: قالب عمومی وردپرس.

فونت‌های Google Fonts به اتصال اینترنت نیاز دارند. این پوشه فقط کد قالب را دربرمی‌گیرد؛ وردپرس، پایگاه داده و افزونه‌ها همراه آن نیستند. بارگذاری روی GitHub به‌تنهایی سایت را آنلاین نمی‌کند.

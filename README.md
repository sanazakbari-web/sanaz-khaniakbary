## About

I design and build WordPress websites for businesses, combining custom interfaces with AI-assisted development. This repository contains the custom theme source for two projects, with installation notes for each.

These are WordPress themes and require a PHP/WordPress environment. Uploading the source to GitHub does not deploy a live WordPress website.
